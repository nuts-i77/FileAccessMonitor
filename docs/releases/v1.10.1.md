## English

### Fixes

- **Permissions** tab: when a scan stopped at a limit, the message asked you to scan a subfolder, but there was no way to pick one. Admins can now scan any folder below a monitored folder: with the button next to a folder in the result, or by typing the folder and pressing **Scan this folder**. Subfolder scans are listed in the folder list below their monitored folder.

### Changes

- A permissions scan reads **folders only** by default. Files nearly always inherit their folder's permissions, and reading each file is what made large shares stop at the file limit. Untick **Folders only (skip files)** to find files with permissions of their own. The result says when a scan read folders only.
- The scheduled report counts a folder that is in more than one scan (a subfolder scanned on its own too) once, from the newest scan.

### Upgrading

- Monitoring server only. Agents are unchanged; 1.10.0 agents work with a 1.10.1 monitoring server. See [v1.10.0](https://github.com/nuts-i77/FileAccessMonitor/releases/tag/v1.10.0) for the changes in 1.10.

## 日本語

### 修正

- **アクセス権** タブ: スキャンが上限で止まると「サブフォルダを指定してスキャンしてください」と表示されるのに、サブフォルダを指定する方法がありませんでした。管理者は、監視フォルダの下の任意のフォルダをスキャンできるようにしました。結果の各フォルダの横のボタンを押すか、フォルダを入力して **このフォルダをスキャン** を押します。サブフォルダのスキャン結果は、フォルダの一覧で監視フォルダの下に並びます。

### 変更

- 権限のスキャンは、既定で **フォルダのみ** を調べるようにしました。ファイルは通常フォルダの権限をそのまま引き継いでおり、大きな共有がファイル数の上限で止まる原因は、ファイルを 1 つずつ読むことでした。個別の権限を持つファイルを探すときは **フォルダのみ（ファイルを含めない）** のチェックを外してスキャンします。フォルダのみのスキャン結果には、その旨を表示します。
- 定期レポートでは、複数のスキャンに含まれるフォルダ（サブフォルダを個別にもスキャンした場合）を、新しいほうのスキャンで 1 回だけ数えます。

### 更新時の注意

- 更新が必要なのは監視サーバーだけです。エージェントに変更はなく、1.10.0 のエージェントは 1.10.1 の監視サーバーとそのまま使えます。1.10 の変更内容は [v1.10.0](https://github.com/nuts-i77/FileAccessMonitor/releases/tag/v1.10.0) を参照してください。
