## English

### Fixes

- **File history** opened from the permission record of a copied file showed "origin unknown" (recording started after the file was created), although the file's Create record follows a few seconds later. The history now starts at that Create and lists it first.

### Changes

- When a file is created, for example by a copy, Windows sets its permissions right away. These records are now labelled **set at creation** (with a tooltip) in the log, the search, the file details and the file history, and show as "Permission (set at creation)" in the CSV exports. They are not counted as permission changes in the scheduled report.
- Records made before 1.10.2 are not labelled. The label needs the Windows monitoring server or agent with the USN journal.

### Upgrading

- Update the monitoring server. Update the agents to 1.10.2 to get the label for their records; 1.10.0 and 1.10.1 agents keep working, without the label. See [v1.10.0](https://github.com/nuts-i77/FileAccessMonitor/releases/tag/v1.10.0) for the changes in 1.10.

## 日本語

### 修正

- コピーしたファイルの権限変更の記録から **ファイル履歴** を開くと、直後に作成の記録があるにもかかわらず「作成元不明（ファイル作成後に記録を開始）」と表示されていました。作成の記録から履歴を始め、先頭に表示するようにしました。

### 変更

- ファイルをコピーなどで作成すると、Windows はすぐにそのファイルの権限を設定します。この記録に **作成時の設定** の表示（ツールチップ付き）を付けました。アクセスログ、検索、ファイルの詳細、ファイル履歴に表示され、CSV では「権限変更（作成時の設定）」と出力されます。定期レポートの権限変更には数えません。
- 1.10.2 より前の記録には表示されません。この表示には、USN ジャーナルを使う Windows の監視サーバーまたはエージェントが必要です。

### 更新時の注意

- 監視サーバーを更新してください。エージェントの記録にこの表示を付けるには、エージェントも 1.10.2 に更新します。1.10.0 / 1.10.1 のエージェントは表示なしでそのまま使えます。1.10 の変更内容は [v1.10.0](https://github.com/nuts-i77/FileAccessMonitor/releases/tag/v1.10.0) を参照してください。
