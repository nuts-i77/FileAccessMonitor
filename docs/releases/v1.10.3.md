## English

### Changes

- **Dashboard click-through.** Click a value in a dashboard chart to see the records behind it:
  - a point of the access trend chart opens that day's records of that type in Search (a click elsewhere on the day opens all types);
  - a slice of the access type chart opens the records of that type in the dashboard's period;
  - a row of the top 10 files or folders opens the file or folder detail.
- **Wording.** The English and Japanese texts of the web GUI, the server messages, the alert and report e-mails and the CSV headers were rewritten to be shorter and more consistent. In Japanese, names of buttons and tabs are now written in ［ ］, and the access types are 読み取り / 書き込み. Some labels changed, for example the Permissions filters **Broad access only** and **Inheritance off only**, and **Folders only** in the scan options. The meaning of every setting is unchanged.
- **Larger text.** The base text size of the web GUI is now 15 px (was 14 px), and hints and notes are 90 % of it (was 87.5 %).

### Upgrading

- Monitoring server only. Agents are unchanged; 1.10.x agents work with a 1.10.3 monitoring server.
- CSV column names changed in places (for example in the permissions export). Update anything that reads the CSV by column name.

## 日本語

### 変更

- **ダッシュボードからの詳細表示。** グラフの値をクリックすると、その元になった記録を表示します。
  - アクセス推移グラフの点: その日のその種別の記録を［検索］タブで表示（その日の点以外の場所をクリックすると全種別）
  - アクセス種別のグラフ: その種別の、ダッシュボードの期間の記録を表示
  - 上位 10 ファイル・フォルダのグラフの行: ファイルまたはフォルダの詳細を表示
- **文言の見直し。** Web 画面、サーバーのメッセージ、通知メールとレポートメール、CSV の列名の日本語と英語を、簡潔で統一された表現に改めました。日本語では、ボタンやタブの名前を［ ］で示し、アクセスの種別を「読み取り」「書き込み」に統一しました。一部の表示名が変わっています（例: アクセス権の絞り込み［広範囲のアクセスのみ］［継承無効のみ］、スキャンのオプション［フォルダのみ］）。設定の意味は変わりません。
- **文字の拡大。** Web 画面の基本の文字サイズを 15 px（従来 14 px）にし、ヒントや注記は本文の 90 %（従来 87.5 %）にしました。

### 更新時の注意

- 更新が必要なのは監視サーバーだけです。エージェントに変更はなく、1.10.x のエージェントは 1.10.3 の監視サーバーとそのまま使えます。
- CSV の列名が一部変わりました（アクセス権の CSV など）。列名で CSV を読み込んでいる処理があれば合わせてください。
