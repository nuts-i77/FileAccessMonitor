## English

### Fixes

- **How to update** (Agents list): the PowerShell commands for a Windows agent saved the installer under a wrong path, so the download failed with "Access to the path ... Temp is denied" and nothing was installed. The commands now save it as `%TEMP%\FileAccessMonitor-Setup-<version>.exe` and run it.

### Upgrading

- Monitoring server only. Agents are unchanged. See [v1.10.3](https://github.com/nuts-i77/FileAccessMonitor/releases/tag/v1.10.3) for the changes in 1.10.3.

## 日本語

### 修正

- ［更新手順］（エージェント一覧）: Windows エージェント用の PowerShell コマンドで、インストーラーの保存先のパスが誤っていたため、「パス ... Temp へのアクセスが拒否されました」となり、ダウンロードできませんでした（何もインストールされません）。`%TEMP%\FileAccessMonitor-Setup-<バージョン>.exe` に保存して実行するように直しました。

### 更新時の注意

- 更新が必要なのは監視サーバーだけです。エージェントに変更はありません。1.10.3 の変更内容は [v1.10.3](https://github.com/nuts-i77/FileAccessMonitor/releases/tag/v1.10.3) を参照してください。
