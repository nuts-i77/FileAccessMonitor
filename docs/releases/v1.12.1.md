## English

### Fixes

- **Search did not find a rename by the new name.** A rename's record keeps the old path as its path and the new one as "moved to", and the search keywords were only matched against the path. Searching for the new name, as **Open in Search** in a file's history does, missed the rename itself. Keywords now also match the new path (also in the CSV export).
  For a viewer limited to folders, keywords still do not match the new path: it may lie outside their folders, and a match would tell that it exists.

### Upgrading

- Only the monitoring server changed. Agents of 1.12.0 do not need an update.

## 日本語

### 修正

- **変更後の名前で検索すると、名前変更の記録が見つかりませんでした。** 名前変更の記録では、パスが変更前のもので、変更後のパスは「移動後の場所」に入っています。検索のキーワードはパスとだけ照合していたため、ファイルの履歴の［検索で開く］のように変更後の名前で検索すると、名前変更の記録そのものが出ませんでした。キーワードを移動後の場所とも照合するようにしました（CSV 出力も同じ）。
  閲覧範囲を限った Viewer では、引き続き移動後の場所とは照合しません。移動先が範囲の外にある場合、検索に当たることで移動先の存在が分かってしまうためです。

### 更新時の注意

- 変更は監視サーバーだけです。1.12.0 のエージェントは更新しなくても構いません。
