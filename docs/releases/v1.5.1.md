## English

### Fixes

- Upgrading with the installer removed the firewall rule for the agent port 8443 when the earlier install had not created it (for example, a rule added by hand after v1.4 or earlier). Agents then could not reach the monitoring server until the rule was added again. The installer now keeps firewall rules that already exist, and removes them only when uninstalling.

### Upgrading

- If you upgraded the monitoring server to v1.5.0 and agents stopped connecting, add the rule again on the monitoring server (as administrator), then upgrade to v1.5.1:
  ```powershell
  New-NetFirewallRule -DisplayName "File Access Monitor Agents" -Direction Inbound -Protocol TCP -LocalPort 8443 -Action Allow -Profile Any
  ```
  Records wait on the agents meanwhile and are sent once they reconnect.
- See [v1.5.0](https://github.com/nuts-i77/FileAccessMonitor/releases/tag/v1.5.0) for the changes in 1.5.

## 日本語

### 修正

- インストーラーで更新すると、エージェント用ポート 8443 のファイアウォール規則が消えることがありました。前回のインストールでその規則を作っていなかった場合（v1.4 以前の環境に手動で規則を追加した場合など）に起こります。規則が消えると、追加し直すまでエージェントが監視サーバーに接続できません。今後は既存のファイアウォール規則を残し、削除するのはアンインストール時だけにしました。

### 更新時の注意

- 監視サーバーを v1.5.0 に更新してエージェントが接続できなくなった場合は、監視サーバーで管理者として次を実行して規則を追加し直し、v1.5.1 に更新してください。
  ```powershell
  New-NetFirewallRule -DisplayName "File Access Monitor Agents" -Direction Inbound -Protocol TCP -LocalPort 8443 -Action Allow -Profile Any
  ```
  その間の記録はエージェントに残り、接続が戻ると送られます。
- 1.5 の変更内容は [v1.5.0](https://github.com/nuts-i77/FileAccessMonitor/releases/tag/v1.5.0) を参照してください。
