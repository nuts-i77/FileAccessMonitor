## English

### Changes

- **Adding an agent no longer needs a service restart.** The monitoring server always listens on the agent port 8443, so **Settings → Agents → Issue registration code** gives a connection string straight away. Only registered agents, or agents with a valid registration code, are accepted there; the web GUI is not served on that port.
- **One firewall rule for the program.** The installer's firewall option now adds a single rule, **File Access Monitor**, that allows FileAccessMonitor.exe. It covers the web GUI port and the agent port, also after either port is changed. On upgrade, the earlier port rules **File Access Monitor Web** and **File Access Monitor Agents** are replaced by it.
- The agent port can be changed in `settings.json`, or turned off with `"Agents": { "Enabled": false }`. See "Collect from several file servers" in the README for the steps.

### Upgrading

- Run the new installer on the monitoring server and on each agent; settings and records are kept.
- If the monitoring server had any **File Access Monitor** firewall rule, the upgrade replaces it with the program rule, which also allows port 8443. If you do not want port 8443 reachable, set `"Agents": { "Enabled": false }` in `C:\ProgramData\FileAccessMonitor\settings.json` and restart the service.

## 日本語

### 変更点

- **エージェントの追加でサービスの再起動が不要になりました。** 監視サーバーは常にエージェント用ポート 8443 で待ち受けるので、**設定 → エージェント → 登録コードを発行** を押すとすぐに接続文字列が出ます。このポートで受け付けるのは、登録済みのエージェントと、有効な登録コードを持つエージェントだけです。Web GUI はこのポートでは表示しません。
- **ファイアウォール規則を、プログラム単位の 1 つにまとめました。** インストーラーのファイアウォールのオプションは、FileAccessMonitor.exe を許可する規則 **File Access Monitor** を 1 つだけ追加します。Web GUI のポートとエージェント用ポートの両方が対象で、どちらかのポートを変えても規則の変更は不要です。更新時には、以前のポート単位の規則 **File Access Monitor Web** と **File Access Monitor Agents** をこの規則に置き換えます。
- エージェント用ポートは `settings.json` で変更できます。`"Agents": { "Enabled": false }` を指定すると開きません。手順は README の「複数のファイルサーバーから収集する」を参照してください。

### 更新時の注意

- 監視サーバーと各エージェントで新しいインストーラーを実行してください。設定と記録は引き継がれます。
- 監視サーバーに **File Access Monitor** のファイアウォール規則があった場合、更新でプログラム単位の規則に置き換わり、ポート 8443 も許可されます。8443 に外から接続させたくない場合は、`C:\ProgramData\FileAccessMonitor\settings.json` に `"Agents": { "Enabled": false }` を指定してサービスを再起動してください。
