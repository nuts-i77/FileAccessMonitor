## English

### Highlights

**The monitoring server runs on Linux.** The web GUI, database, notifications and agent port now also run on x86-64 Linux with systemd, from `FileAccessMonitor-1.8.0-linux-x64-server.tar.gz`:

```sh
sudo sh install.sh              # monitoring only (runs as the user fileaccessmonitor)
sudo sh install.sh --collect    # also records this machine's Samba accesses (runs as root)
```

Windows and Linux agents connect to it as they do to a Windows monitoring server. See "Monitoring server on Linux" in the README.

**Monitoring server only.** A monitoring server can now leave out its own accesses and only show what agents send, on Windows too. The installer has a new choice, **Monitoring server only**: it does not read the Security log, change the audit policy or set SACLs on that machine, and the machine is not listed as a file server. Switch an existing install with `FileAccessMonitor.exe local-collection off` (or `on`) and a service restart; **Settings → App info** shows the mode.

### Other changes

- The Linux agent download is now named `FileAccessMonitor-<version>-linux-x64-agent.tar.gz`.
- A machine runs either the monitoring server or the agent: each Linux installer refuses to install next to the other.

### Upgrading

- Windows: run the new installer; existing installs keep recording accesses on the server as before.
- Linux agents from 1.7 work with a 1.8 monitoring server; upgrade them so their version matches.

## 日本語

### 主な変更

**監視サーバーが Linux でも動くようになりました。** Web GUI、データベース、通知、エージェント用ポートが、systemd の動く x86-64 の Linux でも動きます。`FileAccessMonitor-1.8.0-linux-x64-server.tar.gz` から導入します。

```sh
sudo sh install.sh              # 監視専用（ユーザー fileaccessmonitor で動きます）
sudo sh install.sh --collect    # この機械の Samba のアクセスも記録（root で動きます）
```

Windows 版・Linux 版のエージェントは、Windows の監視サーバーと同じように接続できます。詳しくは README の「Linux の監視サーバー」を参照してください。

**監視サーバーのみ（監視専用）にできるようになりました。** Windows でも、監視サーバー自身のアクセスは記録せず、エージェントから届いた記録だけを表示できます。インストーラーに **監視サーバーのみ** を追加しました。この場合、その機械のセキュリティログは読まず、監査ポリシーや SACL も変更せず、ファイルサーバーの一覧にも出しません。インストール済みの環境は `FileAccessMonitor.exe local-collection off`（または `on`）を実行してサービスを再起動すると切り替わります。今の状態は **設定 → アプリ情報** に表示されます。

### その他の変更

- Linux エージェントのファイル名を `FileAccessMonitor-<バージョン>-linux-x64-agent.tar.gz` に変えました。
- 1 台の機械には、監視サーバーとエージェントのどちらか一方だけを入れます。Linux のインストーラーは、もう一方が入っている場合は導入しません。

### 更新時の注意

- Windows: 新しいインストーラーを実行してください。既存の環境は、これまでどおりサーバー自身のアクセスも記録します。
- 1.7 の Linux エージェントは 1.8 の監視サーバーとそのまま使えます。バージョンをそろえるため、更新してください。
